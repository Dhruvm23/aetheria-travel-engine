# Aetheria Agent Instructions
- **Stack:** Next.js 15 (App Router), React, TypeScript, Tailwind CSS, Lucide React, Vitest.
- **Strict Guidelines:** All code must use TypeScript with explicit types (no `any`). Use absolute paths (`@/components/*`).
- **UI Design Aesthetic:** High-end architectural luxury. Base background: `#0d0f12`. Glassmorphism panels: `backdrop-blur-md bg-white/5 border border-white/10`. Subtle transitions, high-contrast warm typography, and sleek responsive grids. 
- **Accessibility (100 Score):** Every interactive element must feature a `tabIndex`, semantic HTML tags, and explicit `aria-label` descriptions.
- **Security:** Private API credentials must strictly use `process.env.GEMINI_API_KEY` and `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`.
